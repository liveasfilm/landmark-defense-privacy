# Landmark Defense — Privacy Policy

랜드마크 방위대 (Landmark Defense) 모바일 게임의 개인정보처리방침 공개 페이지입니다.
게임 소스 코드는 이 저장소에 포함되지 않습니다.

- 공개 URL: https://liveasfilm.github.io/landmark-defense-privacy/
- 언어: 한국어 · English (한 페이지 내 탭 전환)
- 최종 수정일: 2026-10-01 (광고·인앱결제 포함 첫 출시 기준)

## 스토어 등록 시 사용

| 항목 | 값 |
|---|---|
| Google Play → 앱 콘텐츠 → 개인정보처리방침 URL | `https://liveasfilm.github.io/landmark-defense-privacy/` |
| App Store Connect → 앱 정보 → 개인정보 보호 정책 URL | `https://liveasfilm.github.io/landmark-defense-privacy/` |
| AdMob → 개인 정보 보호 및 메시지 → 유럽 규정 메시지 | 같은 URL |

## 수정 방법

`index.html` 한 파일만 수정하고 `main`에 push하면 GitHub Pages가 자동 재배포합니다.

> iOS ATT 미요청, 분석 SDK 없음** 상태 기준입니다. Firebase Analytics, 크래시 리포팅,
