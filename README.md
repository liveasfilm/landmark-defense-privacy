# Kaiju Defense — Privacy Policy (redirect)

괴수 방위대 (Kaiju Defense, 옛 이름 랜드마크 방위대) 개인정보처리방침의 옛 주소입니다.
이 페이지는 현재 방침으로 바로 넘어가는 리디렉션만 담고 있습니다.

- 옛 주소: https://liveasfilm.github.io/landmark-defense-privacy/
- 현재 방침: https://liveasfilm.github.io/landmark-defense-site/privacy.html
- 방침 수정: [liveasfilm/landmark-defense-site](https://github.com/liveasfilm/landmark-defense-site)의 `privacy.html`

## 이 저장소를 지우면 안 되는 이유

아래 항목과 Google Play 스토어 설명에 옛 주소를 등록했습니다. 모두 새 주소로 바꾸기 전에는
이 페이지를 유지해야 합니다.

| 항목 | 값 |
|---|---|
| Google Play → 앱 콘텐츠 → 개인정보처리방침 URL | `https://liveasfilm.github.io/landmark-defense-privacy/` |
| App Store Connect → 앱 정보 → 개인정보 보호 정책 URL | `https://liveasfilm.github.io/landmark-defense-privacy/` |
| AdMob → 개인 정보 보호 및 메시지 → 유럽 규정 메시지 | 같은 URL |
